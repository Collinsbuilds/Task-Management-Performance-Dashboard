# Task Management & Performance Dashboard
## Project Overview

A spreadsheet-based task management project built with Google Sheets to organize tasks, monitor deadlines, and track completion performance using spreadsheet formulas and data validation.

## Objectives

- Organize and monitor task statuses.
- Calculate days remaining until deadlines.
- Identify overdue tasks and compare due dates with completion dates.
- Improve data consistency and task management.

## Tools & Skills

- **Tool:** Google Sheets
- **Formulas:** IF, OR, TODAY, and date arithmetic
- **Data Validation:** Controlled data entry and consistent task status selection
- **Skills:** Logical functions, deadline tracking, data quality, and spreadsheet management

## Key Features

- **Task Tracking:** Structured task register for monitoring progress and task status.
- **Data Validation:** Applied validation rules to improve data consistency and reduce invalid entries.
- **Deadline Monitoring:** Automated days-remaining calculations and identification of overdue tasks.
- **Completion Tracking:** Compared due dates with actual completion dates to evaluate deadline performance.

## Project Outcome

Applied spreadsheet formulas and data validation to create a more structured approach to task tracking, deadline monitoring, and completion performance.
